## 常見部署問題

- Root Directory 設錯，找不到 requirements。
- Start Command 使用固定 Port。
- Service Account JSON 格式錯誤。
- PDF／FAISS 檔案在重新部署後沒有持久保存。
- 免費方案休眠造成第一次請求較慢。
