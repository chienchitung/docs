當系統只有一個工具時，可以直接呼叫函式；當資料來源與流程開始增加，就需要用 State 保存任務進度，並用 Router 決定下一步。

## 定義 Data Machi State

```python
from typing import TypedDict

class DataMachiState(TypedDict):
    messages: list
    user_query: str
    query_intent: str
    selected_tools: list[str]
    tool_results: dict
    sources: list[dict]
    retry_count: int
    final_answer: str
```

這些欄位可以分成三類：

- **使用者上下文**：messages、user\_query
- **業務資料**：query\_intent、tool\_results、sources
- **流程控制**：selected\_tools、retry\_count、final\_answer

## 第一版 Graph

```text
START
  ↓
解析意圖
  ↓
Router
  ├─ 指標問題 → Sheets Tool
  ├─ 文件問題 → Document Search
  └─ 一般問題 → Direct Answer
  ↓
整合答案
  ↓
END
```

```python
from langgraph.graph import StateGraph, END

graph = StateGraph(DataMachiState)
graph.add_node("classify", classify_intent)
graph.add_node("query_sheets", query_sheets)
graph.add_node("search_docs", search_docs)
graph.add_node("direct_answer", direct_answer)
graph.add_node("synthesize", synthesize)

graph.set_entry_point("classify")
graph.add_conditional_edges("classify", route_query, {
    "sheets": "query_sheets",
    "docs": "search_docs",
    "direct": "direct_answer",
})
graph.add_edge("query_sheets", "synthesize")
graph.add_edge("search_docs", "synthesize")
graph.add_edge("direct_answer", END)
graph.add_edge("synthesize", END)

app = graph.compile()
```

## Router 的測試方式

不要只測最終回答，也要直接測 Router：

```text
「Q2 客訴有多少件？」       → sheets
「SLA 的正式定義是什麼？」   → docs
「請解釋什麼是 RAG」         → direct
```

<Note>
  Router 的工作是選擇處理路徑，不是直接完成整個任務。當分類與執行責任分離後，錯誤會更容易定位。
</Note>
