Trello 與 Confluence 都屬於選配服務。沒有 Atlassian 帳號的讀者，仍然可以先完成 Gemini、Google Sheets 與 PDF RAG 版本。

## 兩個服務解決不同問題

| 服務 | 適合回答 |
| --- | --- |
| Trello | 專案目前做到哪裡、有哪些卡片、誰負責 |
| Confluence | 名詞定義、政策、流程與正式文件內容 |

## Trello 需要準備

- 一個匿名測試 Board
- Board ID
- API Key
- 使用者授權 Token

```env
TRELLO_BOARD_ID=
TRELLO_API_KEY=
TRELLO_TOKEN=
```

## Confluence 需要準備

- Confluence Site URL
- 帳號 Email
- API Token
- 對目標 Space 與 Page 的讀取權限

```env
CONFLUENCE_URL=
CONFLUENCE_USERNAME=
CONFLUENCE_API_TOKEN=
```

## 權限觀念

API 不會自動突破原本的頁面權限。帳號在網頁中看不到的內容，透過 API 通常也讀不到。教學與公開範例請建立匿名資料，不要連接真實內部空間。

## 選擇你的版本

```text
基礎版：Gemini + Sheets
知識版：Gemini + Sheets + PDF
完整版：再加入 Trello + Confluence
```
