Groq 在 Data Machi 中不是主要聊天模型，而是用來執行語音轉文字。把不同任務交給不同服務，是產品設計的一部分：Gemini 負責理解與整理，Whisper 類模型負責轉錄音訊。

## 會議功能的資料流

```text
錄音或上傳音檔
  ↓
音訊格式轉換
  ↓
Groq Whisper 產生逐字稿
  ↓
Gemini 整理摘要、議程與 Action Items
  ↓
前端保存與呈現
```

## API Key 可以有兩種管理方式

1. 由產品管理者放在 Render Environment，所有使用者共用。
2. 由每位使用者在前端功能中自行輸入，後端只在該次請求中使用，不長期保存。

Data Machi 採用第二種方式，能避免公開 Demo 持續消耗同一組語音額度，也讓使用者對自己的憑證負責。

## 申請與驗收

建立 Groq 帳號與 API Key 後，先使用一段不含敏感資訊的短音檔測試。成功標準不是只有 API 回傳 200，而是逐字稿可讀、語言正確，且長音檔失敗時有清楚提示。

<Warning>
  音檔可能包含個人資料與機密內容。公開教學務必使用自行錄製的匿名測試音訊。
</Warning>
