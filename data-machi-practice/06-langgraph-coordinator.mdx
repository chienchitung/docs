Gemini API Key 只能呼叫模型，不能自動取得你的 Google Sheets 資料。要讓後端讀取試算表，還需要一個 Service Account。

可以把 Service Account 想成專門給應用程式使用的機器帳號。你必須把指定試算表分享給它，它才有權限讀取。

## 完整流程

```text
Google Cloud Project
  ↓
啟用 Google Sheets／Drive API
  ↓
建立 Service Account
  ↓
建立 JSON 憑證
  ↓
將 Sheet 分享給 Service Account Email
  ↓
把 JSON 放入本機與 Render Secret
```

## 本機與正式環境

本機可暫時使用 JSON 檔，但必須加入 `.gitignore`。正式環境更適合把完整 JSON 內容放進 `GOOGLE_SERVICE_ACCOUNT_JSON`。

```env
GOOGLE_SERVICE_ACCOUNT_JSON={"type":"service_account","project_id":"..."}
GOOGLE_SHEET_KEY=your_sheet_id
```

## 最常見的錯誤

- 已建立 Service Account，但忘記把 Sheet 分享給它。
- 只填 Sheet ID，卻沒有憑證。
- 把 JSON 檔 Commit 到 GitHub。
- 分享給自己的 Gmail，而不是 Service Account Email。
- Render 中的 JSON 因換行或引號格式錯誤而無法解析。

## 驗收方式

先建立一份匿名測試表，至少包含日期、分類、狀態與數值欄位。讓工具回答一個可人工核對的問題，例如「目前共有多少筆資料？」結果必須和 Sheet 手動計算一致。
