使用者很少每次都把問題說完整。他們可能先問「上個月有多少筆？」接著只說「那台灣呢？」因此 Data Machi 需要記住對話關係，但不能永遠沿用舊資料。

## 需要保存的不是只有聊天文字

- Conversation ID
- 近期對話
- 較早內容的摘要
- 先前使用過的工具與結果
- 本輪釐清選項
- 是否要求最新資料

## 何時沿用，何時重查？

```text
改寫、摘要、延續同一範圍 → 可沿用
出現最新、目前、全部、新期間 → 重新查工具
問題範圍不明 → 先釐清
```

## 釐清不等於拒絕回答

好的釐清問題應直接指出缺少的條件，例如市場、期間或資料來源，並提供可選項，而不是回覆「請提供更多資訊」。

## 驗收情境

測試代名詞、追問、改寫、切換期間與要求最新資料。觀察系統是否錯誤沿用先前結果，或每一輪都不必要地重查。
