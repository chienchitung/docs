在加入 Google Sheets、RAG 或 LangGraph 前，先完成最小閉環：

```text
使用者輸入 → 前端 → FastAPI → Gemini → FastAPI → 前端顯示
```

這一步很重要，因為如果連最基本的模型呼叫都還沒成功，就同時加入多個工具，只會讓錯誤來源更難判斷。

## 本篇要完成的結果

- 前端可以送出一則訊息。
- 後端能讀取 `GOOGLE_API_KEY`。
- Gemini 回傳文字。
- 前端能顯示回答與錯誤狀態。

## 建議先關閉選配能力

暫時不要要求系統查 Sheets、PDF、Trello 或 Confluence。System Prompt 也先維持簡單，確認模型連線正常後，再逐步恢復工具路由與企業規則。

## 驗收問題

使用不需要外部資料的問題，例如「請用一句話介紹你能協助的工作」。若回答成功，代表主幹已打通；若失敗，檢查 API Key、模型名稱、後端 Log 與前端 API URL。
