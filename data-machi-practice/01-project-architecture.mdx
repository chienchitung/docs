第一步不是立刻研究 Agent Prompt，而是先讓整個系統在本機跑起來。Data Machi 採用前後端分離架構：React/Vite 負責互動介面，FastAPI 負責模型、工具與文件處理。

## 專案結構

```text
project-root/
├─ backend/
│  ├─ main.py                 # FastAPI 入口與 API schema
│  ├─ agent_logic.py          # 一輪對話的組裝與後處理
│  ├─ agents/
│  │  ├─ coordinator.py       # LangGraph 與工具協調
│  │  ├─ analyst.py           # 結構化資料查詢
│  │  ├─ document.py          # 文件 RAG
│  │  └─ ...                  # 其他外部系統工具
│  ├─ prompts/                # 模組化系統規則
│  └─ requirements.txt
├─ frontend/
│  ├─ src/                    # React UI 與狀態管理
│  └─ package.json
└─ render.yaml                # 後端部署設定範例
```

## 建立後端環境

```bash
cd backend
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
python main.py
```

預設後端網址：

```text
http://localhost:8000
```

## 建立前端環境

```bash
cd frontend
npm install
npm run dev
```

預設前端網址通常是：

```text
http://localhost:5173
```

## 最小環境變數

```env
GOOGLE_API_KEY=your_model_api_key
GEMINI_MODEL=your_primary_model
GEMINI_FAST_MODEL=your_fast_model
ALLOWED_ORIGINS=http://localhost:5173
```

其他工具的憑證先不要一次全部設定。建議每完成一個實作章節，再加入對應環境變數，避免無法判斷錯誤來自哪個整合。

<Warning>
  不要把 API Key、Service Account JSON、文件網址、看板 ID 或試算表 ID 提交到 Git。所有教學範例都應使用占位符與自己的測試資源。
</Warning>

## 驗收方式

1. 後端可以啟動且沒有 import error。
2. 前端可以開啟。
3. 瀏覽器能向後端送出一則最簡單的聊天請求。
4. 缺少模型金鑰時，系統回傳清楚錯誤，而不是整個服務崩潰。
