很多人第一次看到 AI 專案，會以為只要申請一組模型 API Key 就完成了。但真正能讓使用者每天打開並使用的產品，通常由多個服務共同組成。

## 先分清楚兩張架構圖

### 產品正式運作時

```text
Vercel 前端 → Render 後端 → Gemini／Sheets／RAG／外部工具
```

### 開發者修改產品時

```text
VS Code／雲端 Coding Agent → GitHub → Vercel 與 Render 自動部署
```

Claude Code、Codex 是建造產品的工具；Gemini、Render、Vercel 與資料 API 才是產品上線後需要的服務。

## 服務清單

| 服務 | 用途 | 必要性 |
| --- | --- | --- |
| GitHub | 保存程式碼與版本 | 必要 |
| Claude Code／Codex | 協助修改與測試 | 擇一即可 |
| Gemini API | 理解問題與生成答案 | 必要 |
| Render | 部署 Python 後端 | 必要 |
| Vercel | 部署 React 前端 | 必要 |
| Google Sheets API | 查詢結構化資料 | 建議 |
| PDF RAG | 搜尋文件內容 | 建議 |
| Trello／Confluence | 專案與知識來源 | 選配 |
| Groq Whisper | 會議錄音轉文字 | 選配 |
