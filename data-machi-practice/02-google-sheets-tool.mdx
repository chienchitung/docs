Agent 系統不能只回傳一段文字。真實產品還需要傳遞對話歷史、Conversation ID、釐清選項、文件選擇、執行 metadata 與可分類的錯誤狀態。

## 核心請求模型

```python
from pydantic import BaseModel, Field
from typing import Any, Optional

class Message(BaseModel):
    role: str
    content: str

class ChatRequest(BaseModel):
    message: str
    history: list[Message] = Field(default_factory=list)
    conversation_id: Optional[str] = None
    clarifications: list[dict] = Field(default_factory=list)
    turn_context: dict[str, Any] = Field(default_factory=dict)
    active_documents: list[str] | None = None

class ChatResponse(BaseModel):
    response: str
    error_code: str | None = None
    metadata: dict[str, Any] = Field(default_factory=dict)
```

| 欄位 | 用途 |
| --- | --- |
| `history` | 保留目前瀏覽器中的近期對話 |
| `conversation_id` | 讀取持久化記憶與先前工具結果 |
| `clarifications` | 將使用者選擇的條件結構化送回後端 |
| `turn_context` | 告訴後續流程這輪是追問、改寫或新問題 |
| `active_documents` | 限制本輪只能查哪些文件 |
| `metadata` | 回傳來源、工具、驗證與執行狀態 |

## 錯誤不是 Exception 字串

```python
def product_error(code: str, title: str, message: str, next_steps=None):
    return {
        "code": code,
        "title": title,
        "message": message,
        "next_steps": next_steps or [],
    }
```

建議至少區分模型未設定、模型逾時、知識庫未完成、查無支持資料、工具執行中斷與未預期錯誤。

## CORS 與前端來源

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=ALLOWED_ORIGINS,
    allow_credentials=False,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

正式環境不要使用無限制的 `*`。只允許自己的前端網域與本機開發網址。

## 驗收方式

1. 空白 history 也能正常送出。
2. 非法資料型別會得到清楚的驗證訊息。
3. 缺少 API Key 時回傳產品化錯誤。
4. 前端能依 `error_code` 顯示不同操作建議。
