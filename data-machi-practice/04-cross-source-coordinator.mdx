這一篇把自然語言問題轉成可驗證的資料查詢。核心原則是：LLM 負責理解需求，Python 負責篩選、計算與格式化數字。

## 安全載入憑證

```python
import json, os
from oauth2client.service_account import ServiceAccountCredentials

SCOPES = [
    "https://spreadsheets.google.com/feeds",
    "https://www.googleapis.com/auth/drive",
]

def load_credentials():
    raw = os.getenv("GOOGLE_SERVICE_ACCOUNT_JSON")
    if not raw:
        raise RuntimeError("Missing service account credentials")
    return ServiceAccountCredentials.from_json_keyfile_dict(
        json.loads(raw), SCOPES
    )
```

教學資料必須使用自己的測試試算表，環境變數中只放占位符，不保留任何真實 Sheet ID。

## 欄位別名

```python
COLUMN_ALIASES = {
    "Status": ["狀態", "進度", "status"],
    "Department": ["部門", "單位", "department"],
    "Due Date": ["截止日期", "到期日", "due date"],
}
```

使用者不會精確記得資料表欄位名稱，因此工具需要把自然語言對應到 canonical column，再由程式驗證欄位是否存在。

## 安全讀取與短期快取

```python
import time

CACHE_TTL = 60
_cache = {}

def get_records(cache_key, loader):
    now = time.monotonic()
    cached = _cache.get(cache_key)
    if cached and now - cached[0] < CACHE_TTL:
        return cached[1]
    records = loader()
    _cache[cache_key] = (now, records)
    return records
```

短期快取可以避免同一輪對話重複抓取整張工作表，但 cache key 必須包含資料來源與工作表名稱，避免不同來源互相污染。

## 查詢流程

```text
自然語言問題
  ↓
解析期間、欄位與篩選條件
  ↓
欄位別名轉換
  ↓
載入或命中快取
  ↓
Pandas 篩選與計算
  ↓
回傳數值、列數、條件與資料來源
```

## 驗收方式

- 同一條件重複執行得到一致結果。
- 空白列不會讓讀取提前停止。
- 不存在的欄位會明確報錯。
- 空結果不會被 LLM 補成推測答案。
- 快取過期後能取得新資料。
