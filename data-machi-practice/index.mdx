前面的 30 天系列回答的是：**為什麼企業 AI 需要 RAG、Tool Use、Agent、LangGraph、記憶、查核與可靠性設計？**

實作篇則換一個角度，回答更具體的問題：

> 如果我想建立一套屬於自己的 Data Machi，到底需要準備哪些工具、申請哪些服務，並如何把它們串成一個真正可以上線的產品？

這不是 Python 語法課，也不要求你先成為全端工程師。本系列採用 **Vibe Coding** 的方式：你可以在本機使用 VS Code 搭配 Claude Code、Codex 或其他 AI Coding Agent，也可以透過雲端 Coding Agent 從桌機或手機遠端修改專案。

## 每篇文章都會回答五個問題

1. 這個工具或服務在系統中扮演什麼角色？
2. 為什麼需要它？
3. 要去哪裡申請或設定？
4. 取得的 API Key、URL 或憑證應放在哪裡？
5. 如何判斷串接成功？
