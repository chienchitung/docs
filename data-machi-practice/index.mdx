這個實作篇不會重新發明一套只存在於教學中的範例，而是以 Data Machi 的開源專案為基礎，將一個已經能運作的 AI Agent 系統拆成可理解、可執行、可測試的學習單元。

<Note>
  教學會保留真實架構與工程決策，但所有資料來源、欄位名稱、帳號、網址、試算表識別碼與組織規則都會抽象化。讀者應使用自己的測試資料與 API 憑證，不應複製任何內部識別資訊。
</Note>

## 這套實作會完成什麼？

```text
React 前端
   ↓ HTTP / progress events
FastAPI API
   ↓
對話脈絡與釐清判斷
   ↓
LangGraph Coordinator
   ├─ 結構化資料工具
   ├─ 專案管理工具
   ├─ 知識文件工具
   └─ 本地文件 RAG
   ↓
答案查核、來源整理與錯誤轉譯
   ↓
回傳可理解的結果與執行狀態
```

## 學習原則

每篇文章都會包含：真實問題、對應程式模組、最小實作、測試方法、常見失敗與可再演進的方向。教學重點不是複製完整程式，而是理解為什麼系統需要這一層，以及如何在自己的專案中重建相同能力。

<Info>
  建議先完成實作 01–06，建立核心 Agent 工作流；實作 07–10 則把系統從 Demo 推進到可長期使用的產品。
</Info>
