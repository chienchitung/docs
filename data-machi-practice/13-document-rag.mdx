Google Sheets 適合精確數字，PDF RAG 則適合政策、流程、說明文件與非結構化內容。

```text
PDF → 解析與切割 → Embedding → Vector Index → 搜尋片段 → 生成回答
```

## 實作前準備

請使用自行建立、可公開的 PDF。不要上傳公司政策、客戶資料或內部報告。

## 需要完成的設定

1. 確認 PDF 解析套件可使用。
2. 建立或載入向量索引。
3. 讓使用者可選擇本輪要查哪些文件。
4. Tool 回傳片段、檔名與頁碼等來源資訊。
5. 找不到支持內容時，系統應明確說明資料不足。

## 驗收方式

準備三類問題：文件中明確有答案、需要跨段落整理、文件完全沒有提到。第三類不能由模型自行補齊。
