Gemini 是 Data Machi 的語言模型，負責理解問題、選擇工具、整理資料並產生回答。它不是資料庫，也不應取代 Google Sheets 或文件搜尋。

## 申請前先理解三件事

- API Key 是讓後端呼叫模型的憑證。
- 模型名稱決定使用哪個 Gemini 版本。
- 免費額度、速率限制與計費可能隨服務方案調整，正式使用前要查看帳戶中的最新資訊。


## 為什麼可以使用兩個模型？

Data Machi 可讓主要模型負責使用者看得到的完整回答，較快模型負責分類、釐清與查核等內部步驟。這不是必要條件，但能分開控制品質、速度與成本。

## 最小驗收

先不要串接任何工具，只測試：

```text
前端輸入問題 → 後端收到請求 → Gemini 回答 → 前端顯示文字
```

若失敗，優先檢查金鑰名稱、模型名稱、額度與 Render Log，而不是立刻修改 Agent 架構。
